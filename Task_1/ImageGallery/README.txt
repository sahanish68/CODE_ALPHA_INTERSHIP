RESPONSIVE IMAGE GALLERY

Files:
- index.html: page structure
- style.css: responsive styling and animations
- script.js: image data, category filters, search, lightbox and navigation

Run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Internet is required for Google Fonts and the Unsplash sample images.

You can add images by editing the `images` array in script.js. Each item needs:
title, category, url, and alt.
Categories currently used: nature, cities, animals, travel.

Features:
- Responsive image grid
- Category filters and live search
- Lightbox with previous/next navigation
- Escape and arrow-key keyboard shortcuts
- Hover animations and like buttons
